You can read and write Delta tables from several engines. Each section below
covers one of them. It shows the journeys this site has verified with it: a
journey is a task a reader sets out to do, such as appending rows to a table.

A journey is **verified** when an example on this site runs it, in CI, against
the versions these docs cover. Select a journey to open that
example and download its script.

The other states don't say that an engine can't do something:

- **Not verified here** means no example here runs the journey. The engine
  may well support it. These docs haven't found or written a script that
  proves it.
- **Upstream docs only** means the engine's own documentation says it works,
  but no example here runs it.
- **Doesn't work** means an example here shows it failing, or the API is
  missing in the version tested.
