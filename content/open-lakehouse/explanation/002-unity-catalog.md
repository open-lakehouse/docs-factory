Unity Catalog is an open catalog specification for data and AI: a REST API that
governs tables, files, functions, and models across engines. As a
specification it is pure contract — definition, not compute — and it
*specifies* the catalog capability.

Engines and services *implement* or *consume* this specification; those
neighbors, along with the capability it specifies, appear in the context panel.
