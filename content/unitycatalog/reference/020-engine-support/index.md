Unity Catalog doesn't run queries, so you always reach it through an engine
or a client. For each tool, this page lists the journeys this site has
verified with it: a journey is a task a reader sets out to do, such as
appending rows to a table.

A journey is **verified** when an example on this site runs it, in CI, against
the release these docs cover. The examples run against local storage and a
simulated Amazon S3; to set up real S3, see
[Configure AWS storage credentials and external locations](../../how-to/configure-aws-storage/index.md).
Select a journey to open that example and download its script.

The other states don't say that a tool can't do something:

- **Not verified here** means no example here runs the journey. These docs
  haven't found or written a script that proves it.
- **Upstream docs only** means the tool's own documentation says it works, but
  no example here runs it.
- **Doesn't work** means an example here shows it failing, or the API is
  missing in this release.

## pandas

pandas works with Unity Catalog tables through the `deltalake` package
(delta-rs), which opens a table on S3 by its `uc://` name. On local storage,
it opens the table's `storage_location` path instead. Opening a `uc://` name
on S3 occasionally hangs, about one run in ten; retry it.

To set it up:

- [Query Unity Catalog tables from Python DataFrame libraries](../../how-to/python-dataframes/index.md)
