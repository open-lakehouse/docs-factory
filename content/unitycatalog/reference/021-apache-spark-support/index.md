Spark reaches Unity Catalog tables through the Unity Catalog connector, and
its Iceberg tables through the Iceberg REST API. Metric views need Spark 4.2.

## Set it up

- [Use Spark with Unity Catalog](../../how-to/configure-spark/index.md)
- [Define and query your first metric view](../../tutorials/first-metric-view/index.md)
