# Delta Lake documentation

> Multi-engine, engine-neutral documentation for Delta Lake — usable from Spark, the deltalake Python package, delta-rs (Rust), DuckDB, and Polars.

## How-to guides

- [Query a Delta table as of a version](https://delta.io/docs/how-to/query-a-table-as-of-version): Use Delta time travel to read a historical version of a table.
- [Read a Delta table](https://delta.io/docs/how-to/read-a-delta-table): Load a Delta table into a dataframe from Python, Polars, DuckDB, Rust, or Spark.

## Explanation

- [Delta kernel architecture](https://delta.io/docs/explanation/delta-kernel-architecture): How a shared kernel library lets many engines speak Delta without diverging.
- [What is Delta Lake?](https://delta.io/docs/explanation/what-is-delta-lake): An engine-neutral introduction to the Delta Lake open table format.
